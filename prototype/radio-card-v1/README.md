# 左栏电台卡片 · 初版原型（radio-card-v1）

这是「只有左栏卡片」的初版原型，与 `C:\Yu\dsh-blackhole-radio-lab` 现有工程、阶段 02 成像产物、
正式构建产物彼此隔离。它**不是**已安装插件，也**不是** DSH 宿主内的实机渲染。

## 它是什么

- 一张完整的左栏底部卡片：电台名 + 收藏星形、歌名 · 歌手 + 喜爱、上一台 / 播放暂停 / 下一台、
  悬停或聚焦向卡片内部横向展开的音量、右侧预览占位区。
- 全部交互只改演示状态：没有音频元素、没有联网、没有探索页面。
- 一个模拟左栏的预览页：会话列表、卡片区、其他插件占位、DSH 原有设置入口同屏，可切换
  264 / 280 / 420 三档左栏宽度与 860 / 640 / 520 / 420 四档窗口高度，并运行几何自检。

## 它不是什么

- 不是宿主插槽兼容证明：预览页里的左栏是模拟容器，不是 `SidebarRoot`。
- 不是多插件共存验收：mneme / 通知 / 表情 只是占位块。
- 不是播放能力：按钮到「演示播放状态」为止。
- 不是正式接入：`sidebar.footer.card` 尚未进入正式宿主，当前 rc.3 宿主不声明该槽。

## 本地查看

需要 Node 20+（本机为仓库自带环境，未安装新依赖；esbuild 复用父仓库 `node_modules`）。

```bash
cd C:\Yu\dsh-blackhole-radio-lab\prototype\radio-card-v1
node serve.mjs
```

服务器只读、只服务本目录，端口默认由系统分配，启动后打印实际 URL，例如：

```
http://127.0.0.1:39365/preview.html
```

打开后：

1. 顶部工具栏切换左栏宽度 / 窗口高度 / 卡片数量（1↔2）/ 其他插件占位 / 会话列表保留高度；
2. 「运行几何自检」把同一视口坐标系下的区域关系、末卡可达、长文本截断、提示可读、控件不误触
   等结果写进右侧 JSON；
3. 也可在控制台调用 `window.__cardPreview.runChecks()`。

构建插件包（只写本目录 `dist/`）：

```bash
node build.mjs
```

## 目录

| 路径 | 作用 |
| --- | --- |
| `src/model.js` | 演示数据与状态（收藏 / 喜爱 / 播放 / 音量 / 入口意图） |
| `src/card.js` | 卡片 DOM、事件、完整文字提示；与框架无关 |
| `src/card.css.js` | 全部 `.rc-*` 样式，不触碰宿主或其他插件选择器 |
| `src/plugin.js` | 三行 React 宿主壳，向 `sidebar.footer.card` 注册 occupant |
| `src/preview.js` | 模拟左栏、布局预算与几何自检 |
| `index.js` / `cordis.patch.yml` | Host half 与组合入口（`apply()` 为空实现） |
| `dist/client.js` | esbuild 产出的 client bundle（隔离产物，不是正式发布物） |

## 已知边界

- 卡片自然高度约 104px（两卡时含 8px 间距），随字号与内容略变；预览占位区不是最终成像。
- 当前插槽提案与空间预算见阶段 0 目录下的
  `阶段0-卡片落位与宿主承载方案.md`、`阶段0-卡片落位方案补正.md`、
  `阶段0-卡片落位与空间预算-补充说明.md`。
- 「动态预览待实现」是占位标签，动态可拖动黑洞预览仍是后续目标，本原型不把它当作已定方案。
