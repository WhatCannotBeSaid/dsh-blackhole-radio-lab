## 3. 状态机与场景转换

- 单一状态机，同一时刻只有一个 `ui` 与一个 `mode`；`state` 由 `mode + transitioning + target` 推导。
- 转换进度 `progress` 是唯一驱动源：黑洞核心/光子环/吸积盘透明度、星团混合量、背景压暗、相机 home 与目标全部由它插值，因此正向、反向、中途改道共用一条曲线。
- 进入：`enterCluster(category)` → `target=1`，保存当前黑洞相机 home；退出：`exitCluster()` → `target=0`，恢复保存的 home。
- 动画中再次操作：`enterCluster` 从当前 progress 继续，`exitCluster` 反向跑同一曲线；不会并行创建第二套动画或第二个相机控制。
- 页面卸载：停 rAF、清 hover/长按计时器、移除全部指针/键盘/ResizeObserver、dispose 几何/材质/renderer、`forceContextLoss()`、移除 canvas；重复挂载不重复注册。

## 4. 黑洞模式交互实测

- 默认态：只有黑洞、光子环、吸积盘与背景星域；DOM 中无 `.bhr-search`、无分类侧栏、无详情卡；左上词标 + 「第四阶段 · 演示数据」，右上关闭，底部一行提示。
- 点击中心：搜索层出现（`ui=search`），`.bhr-search__input` 自动获得焦点，placeholder「搜索电台、国家、语言或分类」；`Esc` 或遮罩关闭后回到 `black-hole`。
- 空状态：输入 `zzzzqq` → 「没有匹配的模拟电台」，结果行 0。
- 键盘：`.bhr-core` 可聚焦，聚焦后 Enter 打开搜索并聚焦输入框；canvas 亦可 Tab 聚焦、Enter/Space 打开搜索。
- 触屏：合成 `pointerType:'touch'` 的 pointerdown 落在中心，560 ms 后分类面板打开（`ui=category-panel`），等价入口成立。
- 拖动：超过 6 px 即取消点击与停留计时，不会误开面板或误选电台；滚轮以黑洞中心缩放，半径夹取 6–44。

## 5. 分类面板实测

- 停留 600 ms 后出现；渐显 240 ms（目标 180–280 ms）；关闭延迟 320 ms（目标 250–400 ms）。
- 面板位于黑洞右侧（left: calc(50% + 104px)），不覆盖中心点击区；从黑洞移入面板不会关闭（canvas 的 pointerleave 不再直接 dismiss，改由 document 级指针跟踪判断「真正离开」）。
- 计数来自 `repository.list()` 按 `station.categories` 汇总的真实成员数，2,000 台时：音乐综合 619、新闻资讯 428、谈话与播客 408、古典音乐 247、爵士乐 267、电子音乐 260、世界音乐 263、环境音乐 214；5,000 台时为 1548 / 1080 / 977 / 639 / 635 / 691 / 637 / 503。
- 点击中心始终优先进入搜索，悬停只展开面板不选中分类；面板按钮 `pointerdown` 阻止冒泡，不会穿透到 canvas。

## 6. 星团布局与视觉参数

- 成员判定：`station.categories` 包含所选分类（含次级分类），稳定 ID 不变。
- 分布：`r = R · u^1.9`（中心致密）、球面均匀方向、y 压扁 0.82、46% 概率向 3 条种子纤维轴拉偏 0.62、半径 4.5% 抖动、核心地板 0.055R；`R = clamp(2.32·(n/520)^0.34, 1.5, 4.6)`。
- 相机：`radius = R·4.35`、`phi=1.17`、`theta=0.62`；最小距离 `max(1.6, 1.55R)`，最大 `min(44, max(18, 9R))`，无平移，禁止穿过中心。
- 渲染：仍是单个 `Points`；每站 5 个 sprite（精选 8），星团目标处散成 2–5 px 小星结（`knotScale = 0.02R`），核心 sprite 不放大，颜色以暖白核心过渡到冷白边缘、分类色仅 8%；星团模式下叠加更紧的星点剖面（halo 0.40 + core 0.60），非成员随 `uClusterAmount` 淡出。
- 参考图对照：中心亮核 + 外围稀疏细星 + 纯黑负空间，无球壳边界、无彩色星云、无装饰光环。

## 8. 星团交互与返回实测

- 点击星点：命中对应稳定 ID（如 `mock-0002`），详情卡显示名称、ID、国家、语言、分类、简介与「演示数据」说明；高亮标记跟随；`focus` 后相机 mode='focus'，目标与星点世界坐标一致。
- 相机：左键拖动绕星团中心旋转，滚轮以星团中心缩放；实测半径 8.34 → 6.50，连续滚动被夹在 3.016–18 之间，未出现翻转。
- 跨模式搜索：jazz 星团内搜索「新闻」→ 点结果 → 平滑进入 news 星团（515/1080 台）并聚焦 `mock-2185`（京都 Studio），搜索层关闭、分类面板未被误开。
- 返回：`Esc` 或左上「黑洞」→ 1.5 s 内 progress 1→0，黑洞核心/光子环/吸积盘恢复，电台散回原吸积盘布局（不重新随机），相机 home 半径 10.88、theta 0.263，黑洞回到画面中心。

## 11. 已知限制

1. 控制台会出现一次 `THREE.WARNING: Multiple instances of Three.js being imported.`。功能不受影响，来源未完全定位（疑似 chunk 在多次挂载间被重复求值），记录为已知告警。
2. 星团视觉针对 267–635 台调过参；分类成员少于约 150 台时星团会更小更稀，属数据量差异，不复制电台凑密度。
3. `?bhrStations=5000` 是调试覆盖，不是正式配置；正式配置上限仍为 20,000。
4. 性能数字来自 Intel Arc 集显 + 144 Hz 窗口；60 Hz 设备会以 vsync 封顶。
5. 转场首帧包含几何上传与材质切换，p95 会短时升高；这是过渡成本，不是稳态掉帧。
6. 桌面宿主（Electron）在启动时计算 chunk revision；本次验证走独立 web profile。桌面端需要重启 DSH 才能加载 0.4.0 的 `client.stage.js` 与新的 `client.js`。
