# Black Hole Radio — 第三阶段返工报告

版本 0.3.1 · 2026-10-22

本次返工只改第三阶段的视觉与空间逻辑：电台不再是环外一圈亮点，而是吸积盘本体里的发光
微结构；默认状态是一整圈混合盘面，分类筛选才把目标分类在盘内显影为星云团。

---

## 一、默认分布算法（src/radio/distribution.js，297 行）

旧实现按分类给 8 个簇心，每个分类占一个扇区，精选电台沿光子环等距排一圈。新实现把所有
电台放进**同一个与分类无关的吸积盘参数场**。

| 参数 | 值 | 含义 |
| --- | --- | --- |
| R_IN | 1.54 R | 盘内缘（DISK_INNER 1.40 + 0.14） |
| R_OUT | 3.65 R | 盘外缘（DISK_OUTER 4.60 − 0.95） |
| DISK_KNOTS | 11 | 只由种子决定的密度结，与分类无关 |
| KNOT_SHARE | 0.54 | 54% 电台落在密度结附近，46% 弥散 |
| 弥散半径 | `R_IN + (R_OUT−R_IN)·u^1.35` | 外密内疏的盘面密度梯度 |
| 盘厚 | `0.026 + 0.05·t` | 随半径增加的厚度场，高斯扰动 |

- 密度结：`angle = k/11·2π + N(0,0.34)`，`radius = 1.54 + (0.04+0.9u^1.15)·2.96`，
  切向 σ 0.16–0.46 rad、径向 σ 0.07–0.20，按权重 0.6–1.4 加权抽样。密度结只制造
  自然的不均匀，不携带任何分类信息。
- 高度：每个电台的 y 由厚度场抽样，靠近密度结时 ×1.45，形成薄盘而不是平面。
- 分类只写进 metadata（`clouds[]`、`primaryCategory`），从不参与默认位置计算。
- 取消筛选时回到同一组 `layout` 基准坐标，不重新随机，ID 与位置逻辑保持可追踪。

离线度量（2,400 台，seed 20261022）：半径 1.54–3.65，盘外 0 台；整体角度集中度 0.048；
各分类 0.033–0.108，分类平均半径 2.86–3.01，全部铺满整条带；8 近邻同类占比 0.142，
与随机混合的期望 0.15 基本一致 —— 默认状态没有可测的分类聚类。

## 二、电台如何融入吸积盘（src/nodes/stations-layer.js，727 行）

单个 `THREE.Points`，每台 5 个粒子（精选 8 个）：

1. **veil**：零偏移、5.4× 尺寸（精选 3.8×）、19% 强度的宽而暗的底光，让相邻结构连成
   一条亮带，而不是一粒粒的点。
2. **微结构**：4 个沿切向/径向/垂直偏移的小粒子，组成一个局部结节。

Shader 直接复用盘面的开普勒剪切场（与 `src/scene/accretion-disk.js` 同一组
`omega/shear/bands/dens` 公式，噪声取 `src/scene/glsl.js` 的 NOISE_GLSL）：电台只在
盘面亮纹上发亮，暗纹处自动变暗，因此远看时它们和盘是同一层物质。

- 形态：沿投影切向拉长的椭圆精灵（2.15:1），边缘用 `sin(aSeed·31+along·6)` 做不规则
  毛边，不是圆点。
- 光色：内圈奶白 → 外圈琥珀，默认只混 5% 分类色；筛选命中时才升到 55%，保持克制。
- 带内衰减：`uBandInner/uBandOuter` 软边（1.54/3.65），避免字段到自己外缘形成"第二圈点"。
- LOD：远 1.22× → 近 0.60× 的尺寸曲线，配合全局 0.52 透明度；靠近时 `mix(1.0,1.5,near)`
  让单个结节变大可辨，但不把相机压进盘面（近距离盘面 shader 有织纹级走样）。
- 精选：4 段由种子决定的弧，半径 1.50–1.98、切向 σ 0.075–0.13、径向 σ 0.018–0.04，
  实测 18 台落在 1.66–1.79 R，形成内环上一段段更稳、更亮的局部结构，而不是等距亮点。

## 三、分类筛选的云团显影

`setFilter(categoryIds)` 做四件事：

1. 为每台计算目标柱坐标：命中分类的电台飞向它所属分类的 2–3 个云心之一
   （`CLOUD_MIN_RADIUS 2.00` … `CLOUD_MAX_RADIUS 3.30`，切向 σ 0.26–0.52、径向 σ
   0.12–0.24，并乘 2.2 / 1.7 的展宽系数），未命中的回落到自己的 `layout` 基准位。
2. 云边界不是圆：`edge = 1 + 0.42·sin(5.2Δ+φ) + 0.18·sin(11.7Δ−φ)`，抽样时按边缘
   调制半径，形成不规则、有体积感的轮廓。
3. 动画在柱坐标里做指数阻尼（2.5/s），每台有 0–0.45 s 的 `filterDelay` 错峰，取消时
   延迟 ×0.7，看起来是"云团散回盘面"，不是整页重排。
4. 亮度策略是**密度而不是亮度**：命中台的每精灵强度 ×`mix(1.0, 0.90, match)`，同时
   尺寸 ×`1+1.6·match`、数量密度由聚拢产生。早期用 1.5× 提亮，结果三团云直接叠成白块；
   改为降亮度、提密度后，云有层次、不发白。
5. 未命中台透明度退到 13%，成为背景盘面的一部分；云仍然贴在盘内，不会脱离黑洞系统。
6. 云团标签：每个被显影的分类取最大的一团，在质心上方写"分类名 + 数量"，透明度跟
   `filterStrength` 联动，取消筛选后自然消失。

## 四、精选电台

不再沿光子环等距摆一圈，而是 4 段种子驱动的内环弧（见上表）。视觉上它们是内环亮带里
更稳、更密的局部结构，粒子数 8 而不是 5，尺寸 0.118 而不是 0.068，带宽衰减对内环
不生效（0.94 保底），因此近看是一条连续亮弧，而不是"环边加了几个点"。

## 五、命中检测与选中

- 视觉层、数据层、交互层分离：`interactive(index)` 只看"当前是否属于可见结构"
  （`labelVisibility > 0.25`），不依赖精灵是否大到能看见。
- 拾取阈值：`max(10, min(34, screenSize·1.15 + 8))` 像素，节点越小给的容差越大；
  黑洞轮廓仍保留 0.98R 的禁区，避免点穿到核心。
- 位置：拾取、标签、相机全部读**当前动画位置**（`positionInto` / `currentPosition`），
  云团移动过程中不会点错。
- 选中反馈：3D 里 34px 的环 + 1.4× 局部增亮；2D 标签层再画一个 17px 的暗底亮环和四个
  刻度（`rgba(4,6,12,.72)` 打底 + 暖色 1.4px），保证在白热云团上也看得见 —— 这是本次
  返工里唯一"为可点性增加的视觉"，且只出现在选中态。
- 搜索/聚焦：命中后相机沿该电台自身的方位角靠近（`theta = bearing + 0.24`，`phi = 1.10`），
  黑洞落在电台背后而不是镜头前；距离 7.0（精选）/ 6.4（普通），`MIN_RADIUS` 6.0。

## 七、仍存在的限制

1. **云团是密度聚拢，不是体积星云**：靠近看仍是"很多微光点聚成一片"，没有真正的体积
   散射。要更进一步需要每团一个大的软 quad / raymarch 雾层，成本会明显上升。
2. **云团颜色偏白**：叠加混合在密集处仍会把青色压成暖白。若要保住分类色相，需要预乘
   加法或按亮度保留色度的色调映射。
3. **云标签在亮云上可能被吞掉**：文字在云心上方 26px，某些视角仍会落在白热区域。
4. **最近距离受限**：相机下限 6.0 R。再近会暴露第二阶段盘面 shader 的极坐标织纹
   （摩尔纹），所以近距可读性靠精灵随距离放大实现，而不是让镜头扎进盘面。
5. **聚焦仍是"局部结构"级**：6.4/7.0 的距离保住整圈构图，不是真正的微距特写。

## 八、下一步建议

- 为每个云团加 1 个大尺寸软雾 quad（additive，低亮度、边缘噪声），做成体积感的第一层。
- 云命中时给一个"色相保留"的 tonemap：`color = mix(luma, color, 0.6)` 后再 ACES。
- 云标签改放到云团外缘（按质心方向外推 30px），并给暗底 capsule。
- 第二阶段盘面 shader 增加近距离细节淡出（dist < 6 时降低高频噪声权重），之后可把
  相机下限降到 4.5 R，做真正的微距状态。
